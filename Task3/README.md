# 1. Классификация данных и обоснование защиты

| Данные | Необходимость защиты (риски) | Инструменты защиты |
|--------|------------------------------|-------------------|
| **Прямые идентификаторы пациента** (ФИО, паспорт, телефон, email, адрес) | Нарушение ФЗ-152 (персональные данные), утечка PII → репутационные потери, штрафы за каждого субъекта | **At Rest:** TDE (PostgreSQL), AES-256 для файлов<br>**In Transit:** TLS 1.3, Mutual TLS для сервисов<br>**Контроль:** HashiCorp Vault для ключей |
| **Медицинские данные** (диагнозы, анализы, заключения) | Врачебная тайна (ст. 13 ФЗ-323), уголовная ответственность до 4 лет, потеря лицензии | **At Rest:** TDE + отдельные ключи для каждого пациента, шифрование файлов в S3<br>**In Transit:** TLS + VPN для внешних интеграций<br>**Контроль:** AWS KMS или аналог, ротация ключей 90 дней |
| **Платежные данные** (суммы, даты, идентификаторы транзакций) | Финансовые риски, мошенничество, требования 152-ФЗ (ст. 10 - специальные категории) | **At Rest:** TDE, изоляция в отдельной БД<br>**In Transit:** TLS, PCI DSS compliance<br>**Контроль:** WAF, DLP на платежные паттерны |
| **Учетные данные сотрудников** (логины, хеши паролей) | Компрометация всей системы, несанкционированный доступ ко всем данным | **At Rest:** bcrypt/Argon2 для паролей, TDE для остального<br>**In Transit:** TLS<br>**Контроль:** IAM (Keycloak), MFA, аудит неудачных попыток входа |
| **Файлы документов** (сканы паспортов, договоры, направления) | Содержат PII и медицинские данные, полный пакет для identity theft | **At Rest:** AES-256 на уровне объектов (S3 Server-Side Encryption)<br>**In Transit:** TLS, подписанные URL с TTL<br>**Контроль:** VirusTotal API, DLP на контент |
| **Логи доступа** (кто, когда, к каким данным обращался) | Необходимы для расследования инцидентов, но сами содержат PII | **At Rest:** Шифрование, WORM-носители<br>**In Transit:** TLS, отдельный защищенный канал<br>**Контроль:** SIEM (Wazuh/ELK), цифровая подпись для целостности |
| **Резервные копии** | Часто забываемый вектор утечки, содержат все вышеперечисленное | **At Rest:** Шифрование бэкапов отдельными ключами<br>**In Transit:** TLS при передаче в DR<br>**Контроль:** Автоматическое тестирование расшифровки, отдельное хранилище ключей |

## 2. Инструменты защиты (программные и аппаратные)

### 2.1. Шифрование при хранении (Encryption at Rest)

| Инструмент | Назначение | Где применяется |
|------------|------------|-----------------|
| **PostgreSQL TDE (pg_crypto + cluster encryption)** | Прозрачное шифрование таблиц с PII и медицинскими данными | Все БД с чувствительными данными |
| **AWS S3 SSE-S3 / MinIO SSE** | Шифрование объектов на стороне сервера | Document Store (PDF, JPG, сканы) |
| **LUKS / dm-crypt** | Шифрование дисков на физических серверах | Все серверы с данными |
| **VeraCrypt / BitLocker** | Шифрование рабочих станций | Ноутбуки сотрудников с доступом к данным |
| **HashiCorp Vault** | Централизованное управление ключами, ротация, аудит | Все ключи шифрования в одном месте |
| **AWS KMS / Google Cloud KMS** | Managed KMS при использовании облака | Облачная инфраструктура |

### 2.2. Шифрование при передаче (Encryption in Transit)

| Инструмент | Назначение | Где применяется |
|------------|------------|-----------------|
| **TLS 1.3 (OpenSSL / BoringSSL)** | Шифрование всех сетевых соединений | Внешние и внутренние API, веб-интерфейсы |
| **mTLS (Istio / Linkerd)** | Взаимная аутентификация сервисов | Service Mesh между микросервисами |
| **WireGuard / OpenVPN** | VPN для удаленного доступа | Администраторы, внешние интеграции |
| **SSH with key pairs** | Безопасное администрирование | Доступ к серверам (никаких паролей) |
| **Let's Encrypt / cert-manager** | Автоматическое управление TLS-сертификатами | Все публичные эндпоинты |
| **AWS ACM / CloudFlare SSL** | Managed TLS в облаке | Облачные нагрузки |

### 2.3. Автоматизированный контроль

| Инструмент | Назначение | Где применяется |
|------------|------------|-----------------|
| **Wazuh / ELK Stack** | SIEM: сбор и анализ логов, алертинг | Централизованный мониторинг безопасности |
| **Vault Audit Logging** | Аудит доступа к ключам | KMS |
| **Prometheus + Grafana** | Мониторинг метрик безопасности | Система алертов на аномалии |
| **Open Policy Agent (OPA)** | Политики доступа к данным (ABAC) | Контроль запросов к API |
| **SonarQube / Checkmarx** | SAST: статический анализ кода | CI/CD pipeline (чтобы уязвимости не попадали в прод) |
| **Trivy / Clair** | Сканирование контейнеров на уязвимости | Container registry |
| **Falco** | Runtime security для Kubernetes | Обнаружение аномалий в рантайме |
| **Vault Automatic Key Rotation** | Автоматическая смена ключей | KMS |
